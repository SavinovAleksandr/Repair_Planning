# Сводный график ремонтов — автоматическая сборка

## Как работает

Скрипт `build_svod.py` и окно `gui_svod.py` работают **в папке, где лежит программа** (корень репозитория / `C:\Макросы_итог\График ремонтов`).

### Файлы в корне

| Файл | Назначение |
|---|---|
| `Проект Арх РДУ.xlsx` | выгрузка из ПК «Ремонты» (Арх РДУ) |
| `Проект Коми РДУ.xlsx` | выгрузка из ПК «Ремонты» (Коми РДУ) |
| `Приоритет строк по группам для сводного графика.xlsx` | справочник порядка строк (можно хранить постоянно) |
| `Сводный график ремонтов …xlsx` | **итоговый сводник** — создаётся программой и правится вручную |

Если проектов нет в корне — программа ищет их в подпапке `Исходные материалы/` (удобно при разработке).

**Сводный график** всегда ищется **только в корне** программы (не в `Исходные материалы/`). Если файлов несколько — берётся **последний изменённый** (`Сводный график ремонтов*.xlsx`).

## Установка (Windows)

### 1. Python

Python 3.10+ с https://www.python.org/downloads/ — при установке включите **Add python.exe to PATH** и **tcl/tk** (нужно для окна с кнопками).

### 2. Библиотеки

**Без интернета** — папка `установка/`:

```bat
установка\install_offline.bat
```

или из корня программы:

```bat
run_svod.bat --setup
```

(`--setup` сначала ставит пакеты из `установка\wheels\`, при неудаче — из интернета.)

**С интернетом:**

```bat
pip install openpyxl
```

### Зависимости

| Пакет | Откуда | В `установка/wheels` |
|---|---|---|
| `openpyxl` | Excel | да |
| `et_xmlfile` | зависимость openpyxl | да |
| `tkinter` | входит в Python | нет (только с python.org) |
| остальное (`difflib`, `pathlib`, …) | стандартная библиотека Python | — |

Дополнительных pip-пакетов не требуется.

### 3. Проверка

```bat
run_svod.bat --check
```

При сбое GUI смотрите **`gui_error.log`** и **`launch_debug.log`** в корне программы.

## Как пользоваться (Windows)

1. Положите в **корень** актуальные `Проект Арх РДУ.xlsx` и `Проект Коми РДУ.xlsx`.
2. Дважды кликните **`run_svod.bat`** — откроется окно с кнопками **без чёрной командной строки** (запуск через `pythonw.exe`).
3. Нажмите нужную кнопку. Итоговый `Сводный график …xlsx` сохраняется **в том же корне**.

**Диагностика** (если окно не открылось — консоль останется открытой, будут видны ошибки):

```bat
run_svod.bat --debug
run_svod.bat --debug --check
```

Перед каждым сохранением предыдущая версия сводника копируется в `backups/`.

### Окно (GUI)

**Сборка из проектов**

- `Сформировать сводный (только объединение)` — слияние Арх + Коми без приоритетов, оглавления, Ганта, высот.
- `Всё и сразу (пересобрать с нуля)` — полный конвейер: объединение → приоритеты → нормализация → оглавление → высоты → «Диаграмма».
- Чекбокс `С нормализацией текста` — для обеих кнопок выше.

**Применить к существующему своднику** (файл `Сводный график …xlsx` **из корня**)

- `Расстановка по приоритетам` — перечитать сводник и перестроить порядок (учитывает ручные правки).
- `Нормализация текста (H/N)`, `Оглавление`, `Фиксация высот + wrap`, `Диаграмма Ганта`.
- `Обновить диаграмму Ганта` — перестроить лист «Диаграмма» по **текущим датам на Page1** (после ручного переноса сроков).
- `Сравнение с проектами (новая вкладка)` / кнопка **«Построить сравнение с Коми/Арх»** — два листа:
  - **«Сравнение с проектами»** — только изменённые строки, зелёный/красный diff текста и дат;
  - **«вставить в ПК Ремонты»** — те же строки, **plain text** из сводника (без подсветки), фразы «ТР. А.Г.: N ч.», «с включением на ночь», «с переводом на ОВ» и аналоги **удалены** — удобно копировать в ПК «Ремонты».
  - Основа — **Page1 сводника из корня**; эталон — проекты Коми/Арх;
  - на листе **только изменённые строки** (неизменённые скрыты);
  - зелёный текст — добавления; красный зачёркнутый — удаления; жёлтая заливка — изменённые даты; красный блок внизу — строки из проектов, не вошедшие в сводник.
- `Выполнить отмеченное` — запуск отмеченных стадий.

**Прочее**

- `Откатить к предыдущей версии` — восстановление из `backups/`.
- `Открыть сводник в Excel` / `Открыть папку`.

### CLI и служебные команды (`run_svod.bat` с аргументами)

## Правила группировки и сортировки

| № | Группа | Сортировка внутри |
|---|---|---|
| 1 | Ограничения ОЗ | сначала Арх, потом Коми; по дате начала |
| 2 | ЛЭП 220 кВ | по дате начала |
| 3 | ПС 220 кВ | по справочнику, внутри ПС — по дате |
| 4 | ЛЭП 110 кВ | по дате начала |
| 5 | ПС 110 кВ | по справочнику, внутри ПС — по дате |
| 6 | Электростанции | по справочнику, внутри — по дате |
| 7 | АЧР | по дате начала |

Неизвестные объекты из справочника — в конец группы, в консоль выводится предупреждение.

## Устройство выходного файла

- Лист **Page1** — основной сводный график (шапка, оглавление, группы, подписи).
- Заголовок: «… операционной зоны Коми РДУ на \<месяц\> \<год\> г.»; год в грифе «Утверждаю» — актуальный.
- Лист **«Диаграмма»** — Гант-календарь по датам с Page1.
- Лист **«Сравнение с проектами»** и **«вставить в ПК Ремонты»** — создаются по запросу (см. выше).

---

## Валидация исходных проектов

Формат экспорта ПК «Ремонты» определяется автоматически (число строк шапки, колонки дат, имя листа может отличаться от `Page1`). При нераспознанном формате — понятное сообщение об ошибке.

---

## Текстовая нормализация (H и N)

По умолчанию: единые тире, пробелы в единицах (`110 кВ`, `2 ч.`), перенос «ночь»/«ОВ»/«ОШВ» в N, общие сокращения. Отключение: `--no-normalize`. Отчёт по правилам — в консоли/GUI-логе.
